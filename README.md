# My Website

A static site showcasing my career journey, professional experience, key projects, and information about me. The HTML is generated using my locally-hosted LLM on my [home server](https://github.com/matthewkdies/homeserver).

## Sections

- Intro: Me, in a gist.
- Contact: How to reach me.
- Core Expertise and Impact: My recent high-impact projects while on-the-clock.
- Trajectory: The titles I've held so far in my career.
- Recent Work: My recent off-the-clock programming projects.
- More About Me: Getting to know me as a human, not just as a worker bee.
